# Game Development Portfolio - Unity & Unreal Engine

[English](README.en.md) | [Español](README.md)


Portfolio tecnico centrado en programacion de videojuegos con Unity, Unreal Engine, C#, C++ y Gameplay Systems y Herramientas de Desarrollo

## Objetivo del repositorio

Este repositorio cumple dos funciones principales:

1. Servir como repositorio centralizado de mi aprendizaje, proyectos, sistemas y documentación relacionados con programación de videojuegos.
2. Servir como portfolio técnico para mostrar mis conocimientos a reclutadores, estudios y otros desarrolladores.
